# 얼음 .. 땡 !!!

내 펭귄의 뒤에서 넓게 내려다보며 작용·반작용으로 상대를 밀어내는 3D 남극 게임입니다.
민트 UI, 하늘색 바다, 입체 설산·유빙과 다섯 색 목도리 펭귄으로 구성했습니다.

## 시작

**`게임시작.command`**를 실행하고 **http://localhost:8767** 을 엽니다.
Node.js 18 이상이 필요하며 `npm start`로 실행해도 됩니다. 별도 npm 설치는 필요 없습니다.

처음에는 **개념 설명 4단계 → 퀴즈 3개 → 게임 선택** 순서로 진행합니다.
게임 시작 전 로그인 안내가 나옵니다. 닉네임(2~12자)과 비밀번호(6자 이상)로 회원가입하면 됩니다.
로그인은 브라우저를 닫아도 90일 동안 유지됩니다. 로그아웃하면 해제됩니다.

로그인과 기록 저장은 서버가 필요합니다. `얼음땡.html`은 제출·미리보기용 단일 파일이며,
실제 플레이와 계정 기능은 위 서버 주소에서 이용해주세요.

## 조작과 규칙

- 기본 시점은 **가까운 3인칭 따라가기**입니다. 내 펭귄이 화면 아래쪽에 보이고, 바라보는 방향을 카메라가 따라갑니다.
- **좌우 드래그**로 바라볼 방향을, **위아래 드래그**로 돌진 세기를 정합니다.
- 방향키 좌우는 방향, 위아래는 세기, Enter는 돌진입니다.
- 확정하면 모든 펭귄이 동시에 돌진합니다. 조준은 출발 전 상대에게 숨겨집니다.
- 혼자 하기는 나와 나머지 펭귄으로 즉시 시작합니다.
- 온라인 자동 매칭은 5명이 모이면 바로 시작하고, 8초 후 부족한 인원은 AI로 채웁니다.
- 사각 판 밖으로 떨어지면 탈락합니다. 생존자가 줄면 다음 턴부터 판도 작아집니다.
- 게임이 끝나거나 탈락하면 서로 다른 과학 퀴즈 3개를 확인한 뒤 큰 ‘홈으로 돌아가기’ 버튼으로 홈에 돌아옵니다. 다음 게임은 홈에서 직접 시작합니다.
- 마지막 생존자가 라운드 승리입니다. 전원 탈락은 무승부이며, 한 라운드가 끝나면 퀴즈 후 홈으로 돌아옵니다.
- 혼자 하기는 일시정지할 수 있습니다. 함께하는 경기는 계속 진행됩니다.

## 점수와 랭킹

- **빙판 축소 +10점**: 빙판이 실제로 작아질 때마다 살아 있는 펭귄의 레벨과 점수가 올라갑니다.
- **조준 명중 +15점**: 내가 조준한 방향의 상대에게 실제로 부딪히면 지급합니다. 상대가 탈락할 필요는 없습니다.
- 같은 턴에 같은 상대를 반복해서 스치는 충돌은 중복 지급하지 않습니다. 승리나 퀴즈 정답만으로는 점수를 주지 않습니다.
- **이번 기록**은 한 경기 점수이며, 내 최고기록 랭킹은 내 역대 경기 기록을 점수순으로, 전체 펭귄 랭킹은 각 사람의 최고기록을 점수순으로 보여줍니다. 개인 기록은 상위 50개를 보관합니다.
- 계정에는 누적 점수·최고기록·최고 레벨이 저장됩니다. 다시 시작해도 계정 기록은 지워지지 않습니다.
- 점수와 충돌·탈락은 혼자 하기와 자동 매칭 모두 서버가 계산합니다.

## 기록 보관

계정, 비밀번호 해시, 세션, 최고기록은 **`data/accounts.json`**에 자동 저장됩니다.
서버를 껐다 켜도 유지됩니다. 이 파일을 삭제하면 계정과 기록을 복구할 수 없으므로 보관해주세요.
비밀번호 원문은 저장하지 않으며 scrypt 해시를 사용합니다. 로그인 쿠키는 HttpOnly입니다.

같은 Wi-Fi는 `http://이-Mac의-IP:8767`로 접속할 수 있습니다.
게임 방은 메모리에서 관리하므로 서버 재시작 시 경기는 초기화되지만, 계정과 기록은 남습니다.

## 파일

| 파일 / 폴더 | 역할 |
| --- | --- |
| 얼음땡.html | 제출·미리보기용 단일 파일 |
| 게임시작.command | Mac 서버 실행 |
| src/game.js | 3D 캐릭터·배경·따라가기 시점·게임 UI |
| src/account.js / online.js | 계정 UI 통신 / 실시간 경기 통신 |
| src/physics.js / quizzes.js | 공유 물리 계산 / 교육 퀴즈 |
| src/index.html / style.css | 화면 구조 / 민트·하늘색 스타일 |
| server/game-server.cjs | 서버 게임·매칭·점수 판정 |
| server/accounts.cjs | 회원가입·로그인·영구 기록 |
| data/ | 실제 계정·기록 데이터 |
| vendor/ | Three.js 및 라이선스 |

소스를 수정한 뒤 `python3 src/build.py`로 최종 단일 파일을 갱신합니다.
캐릭터와 배경은 이미지를 붙이는 방식이 아니라 코드로 만든 실제 3D 모델입니다.

## science26 풀스택 배포

- `얼음땡-science26.zip`을 업로드 화면의 **풀스택 → zip 업로드**로 올립니다.
- 브라우저 주소: https://science26.bssm.dev/students/1104/
- 한 Node 서비스가 화면과 API를 함께 제공합니다. 에셋은 단일 HTML에 포함되어 있습니다.
- 학교가 자동으로 넣는 `DATABASE_URL`이 있으면 PostgreSQL에 계정·세션·기록을 저장합니다. 추가 환경변수는 필요하지 않습니다.
- 로컬 실행은 기존 `data/accounts.json`을 계속 사용합니다. 로컬 계정 데이터는 업로드 파일에 포함하지 않습니다.
- 학교 컨테이너의 읽기 전용 파일시스템에서 쓰기 작업을 하지 않으며 DB 테이블은 시작할 때 자동으로 만듭니다.
